桌面实时预览技术方案（v0.1.1）

属性说明
技术使用 <iframe> 加载 Selkies WebRTC URL，实时视频流
iframe 尺寸原始 1920×1080，通过 CSS transform: scale() 缩放到面板宽度
外层容器overflow: hidden 裁剪，实际显示约 280×158px（16:9 比例）
交互禁用iframe 上覆盖透明遮罩（pointer-events: none），禁止在缩略图上操作
点击行为点击遮罩 → window.open(desktopUrl, '_blank') 打开完整桌面
多连接Selkies 支持并发连接，预览 iframe 和新标签页完整桌面互不影响
分辨率固定 1080p：Selkies 启动参数 --manual-width=1920 --manual-height=1080
