切换方式

• 侧边栏底部放置主题切换按钮（🌙/☀️）
• 通过 Tailwind CSS dark: 前缀实现
• 默认跟随系统偏好（prefers-color-scheme）
• 用户手动切换后存 localStorage

CSS 变量体系

项目使用 HSL CSS 变量实现主题切换：
--background: 240 21% 15% → hsl(var(--background))
Tailwind 配置通过 hsl(var(--xxx)) 引用，通过 .dark class 切换暗色/浅色。
