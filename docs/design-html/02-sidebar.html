交互行为

Agent 卡片行为

操作行为
点击 Agent 名称区域展开/折叠该 Agent 的 Session 列表
展开时自动选中最近的 Session（如果没有则新建一个）
状态图标● running（绿） / ○ stopped（灰） / ⚠ error（红）显示在名称左侧
模型名显示在 Agent 名称下方（次要文字，text-xs 灰色）
右键菜单启动/停止/设置/复制ID/删除

Session 条目行为

操作行为
点击切换到该 Session 的对话
名称取首条用户消息的前 20 字作为标题，未发送过消息的显示"新对话"
右侧时间今天显示时分，之前显示月日
当前选中高亮背景（rgba(137,180,250,0.12)）
鼠标 hover显示删除按钮 🗑（替换时间显示），点击需二次确认

[+ 新对话] 按钮

属性说明
位置Agent 展开后的 Session 列表顶部
点击效果创建新 Session → 自动选中并切换到空对话
Agent 未运行时也可以创建 Session（但输入框禁用，提示"请先启动 Agent"）

选中逻辑流程

用户点击 Agent
→
展开 Session 列表
→
自动选中最近的 Session
如果没有 Session
→
自动创建一个新 Session
用户点击 Session
→
切换到该 Session 的对话
用户点击 [+ 新对话]
→
创建新 Session
→
自动选中
